Round 5 — "THEY FELL UP.": a chain of giant dominoes topples *upward*, against gravity, along a diagonal arc into a blazing portal of light — with the words "THEY FELL UP." / "GRAVITY LOST, JUDGE." addressed to the judge. Pure Python stdlib, fully procedural and deterministic: `main.py` draws the whole 1024×1024 image pixel by pixel (no assets, no network, fixed seed) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
